# Facit: Lektion 0 (endast för instruktören)

1. **Vilket kommando visar installerad version av Claude Code?**
   `claude --version` (eller `claude -v`).

2. **Vad gör `claude -c`?**
   Fortsätter den senaste konversationen i den aktuella mappen.

3. **Vad är skillnaden mellan `claude "fråga"` och `claude -p "fråga"`?**
   `claude "fråga"` startar en interaktiv session med en första prompt. `claude -p "fråga"` kör en fråga och avslutar, utan interaktiv session.

4. **Varför rekommenderas Git for Windows?**
   Så att Claude Code kan använda Bash-verktyget. Utan det används PowerShell som skalverktyg.

5. **Vad händer när du trycker `Shift+Tab` i en session?**
   Permission mode växlar i den aktuella sessionen, till exempel till plan-läge.

## Bedömning

Godkänt vid minst 4 av 5 rätt. Om en elev missar fråga 3 eller 5 är det värt en genomgång i nästa lektions början, eftersom båda används i lektion 1.
